# 밈 유니버스 · Meme Universe

공개 열람용 밈 컬렉션입니다. 로그인 없이 캔버스·갤러리·테이블, 검색과 분류 필터, 한영 전환, 대표 이미지의 내부 지도를 이용할 수 있습니다.

이 저장소의 `site/`에는 공개용 이미지·영상, 이름·설명·분류와 배치가 들어 있습니다. 자료 편집 기능, 개인 메모, 휴지통 자료와 관리 사이트 인증 정보는 포함하지 않습니다. 방문자가 드래그한 위치는 현재 열람 중에만 적용되며 원본 자료에는 저장되지 않습니다.

## 업데이트

자료 추가·수정은 기존 비공개 관리 사이트에서 진행합니다. 공개할 시점에 최신 공개용 사본을 만들어 이 저장소의 `site/`에 반영합니다. `main`의 공개 파일이 바뀌면 GitHub Actions가 GitHub Pages를 자동으로 갱신합니다.

관리 사이트의 수정이 이 저장소로 즉시 자동 동기화되는 구성은 아닙니다. 전체 백업과 인증 정보는 이 저장소에 올리지 않습니다.
